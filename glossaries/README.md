# 術語庫建置指南（per-game glossary）

新遊戲要建術語庫時照這份文件做。一款遊戲一檔，放在本資料夾。

## 檔案規範

- **檔名**：`<遊戲名>.txt`，小寫英數與 `-`（如 `pokemon-oras.txt`、`dq7.txt`）——**檔名就是 PT 模型選單裡顯示的名字**（代理的 `/v1/models` 回傳本資料夾的檔名清單）
- **格式**：每行 `日文詞->台灣譯名 #备注`（gpt_dict 格式）
  - `#备注` 可省略；`#`、`//` 開頭整行是註解；空行忽略
  - 同一 src 重複出現時**先到先贏**，後面的被跳過並記 WARNING
- **dst 用台灣官方譯名（繁體）**：模型會原樣輸出，繞過任何轉換
- **note 用簡體**：它是給模型看的提示（模型以簡中訓練），寫 `#人名，男性` 這類簡短分類

## 內容準則（從寶可夢實戰學到的）

1. **每一條都要查證權威來源，禁止憑記憶**——教訓：ミツル 官方是「滿充」，憑印象寫成「小勝」會把角色搞成別人（小勝是劍盾主角）。寶可夢查 52poke wiki（zh-hant 變體頁；抓取需瀏覽器 User-Agent，頁面「遊戲人物列表」是全 NPC 對照總表）；其他遊戲查該作官方中文版的 wiki／攻略站
2. **涵蓋範圍**：人名、地名、怪物／寶可夢名、道具、招式、組織、稱號、系統用語（メガシンカ→超級進化 類）
3. **全假名遊戲要加「假名→漢字錨定詞」**：孩童向文本無漢字，模型會猜錯（したがめん→結算鍵、ひつよう→不需要 都是實錄）。把常見假名詞錨定：`したがめん->下畫面`、`こうもく->項目`、`ひつよう->必要`
4. **稱號用「複合＋單獨」雙保險**：`ポケモンはかせ->寶可夢博士` ＋ `はかせ->博士`——複合詞訊號最強，單獨詞涵蓋帶全形空格的變體
5. **避免 1–2 個假名的超短詞條**：匹配是單純子字串包含，短詞會誤中其他詞內部（如 あめ 會中 だいじなあめ）
6. 術語表救得了名詞，**救不了文法層錯誤**——那是模型能力問題（已用雲端模型解決），不要試圖用詞條修文法

## 建好之後

```bash
bash tools/deploy_thor.sh    # 推送 + 同步 + 重啟 + 健康檢查
```

- PT 的模型選單（Translation services 清單 → 服務下方灰色小字子列）**重新打開就會出現新遊戲**，點選即切換——免重啟、免打字
- 術語檔**熱載入**：之後改詞條，deploy 完立即生效（依 mtime＋size 偵測）
- 最省事的路徑：直接請 Claude「幫我建 ○○ 的術語庫」——研究、逐條查證、建檔、部署一條龍（未來可寫 tools/build_glossary.py 做整批抓取）
